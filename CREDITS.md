# Credits & Third-Party Licenses

**Sushi Empire: Tokyo** is an original game. No external art, models, music or sound files are used.

- **3D art** — every model (characters, buildings, sushi, props) is generated procedurally in code at runtime.
- **Audio** — every sound effect, ambience layer and music track is synthesized at runtime with the Web Audio API.
- **Font** — [Fredoka](https://github.com/hafontia/Fredoka-One) by Milena Brandão, SIL Open Font License 1.1, bundled via `@fontsource/fredoka`.
- **Engine** — [three.js](https://threejs.org), MIT License.
- **Build** — Vite (MIT), TypeScript (Apache-2.0), Vitest (MIT).

All characters, businesses and districts are fictional; Tokyo neighborhoods are stylized, not reproductions.
